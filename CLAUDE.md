# Esko

Privat produktprosjekt for Tim Raaum Kristiansen og Henning. Ikke knyttet til Tims arbeidsgiver.

Esko er 3D-printede pappklyper som gjør Oda-esker om til byggesett for barn. Målet nå er en pitch til Oda om å selge settene på oda.no.

## Les først

- `README.md` for status og mappestruktur
- `docs/konsept.md` for hele tanken og argumentene
- `docs/beslutninger.md` for hva som er bestemt og hva som er åpent
- `docs/testing-og-sikkerhet.md` for CE/EN 71 og materialvalg

## Arbeidsform

- Skriv på norsk.
- Ingen tankestreker (verken korte eller lange) i tekst.
- Norsk tallformat (mellomrom som tusenskille, komma som desimaltegn, kr etter beløpet).
- Jobb iterativt, ett tema om gangen, og still oppklarende spørsmål ved tvil.
- Lever komplette filer, ikke utdrag.
- Når noe blir bestemt, oppdater `docs/beslutninger.md` med dato. Når en antakelse verifiseres, flytt den fra "må verifiseres" til "bestemt".
- Bilder av prototyper legges i `bilder/prototyper/` med dato først i filnavnet.
- STL-filer i `stl/` navngis med klypetype og versjon, f.eks. `rett-v1.stl`, `90grader-v2.stl`.
